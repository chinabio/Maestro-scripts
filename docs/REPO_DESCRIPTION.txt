GitHub repo name:  maestro-exporters
Author:            Pulan Yu <chinabio@gmail.com>

Short description (About):
Maestro user scripts that export selected Project Table entries to Cresset Flare and CCG MOE (proteins vs ligands done right), and convert selected poses to clean 2D V2000 SD files.
