# Screenshots

This folder holds the images referenced by the **Screenshots** section of the
top-level [`README.md`](../README.md). They are placeholders until real captures
are added.

## Expected filenames

The README links to these names, so use them exactly (PNG):

| Filename | What to capture |
| --- | --- |
| `mae2flare-dialog.png` | The *Export selected entries to Flare* dialog |
| `mae2moe-dialog.png` | The *Export selected entries to MOE* dialog |
| `mae2sd2d-dialog.png` | The *Selected to 2D SD* dialog (with neutralize options) |
| `result-imported.png` | The exported complex loaded in Flare/MOE |

Optional extras already stubbed as commented links in the README:

| Filename | What to capture |

## Capture tips

- Use **PNG** for crisp UI text; keep width around **1200–1600 px**.
- Crop to the relevant window — avoid capturing the whole desktop.
- Scrub any sensitive project/compound names before committing.
- Keep files reasonably small (ideally < 500 KB each); compress if needed.
- If you rename or add images, update the `<img>`/`![]()` links and the table
  in the top-level README accordingly.

> Tip: until real images exist, GitHub will show a "broken image" icon for these
> links. That is expected for a fresh checkout.
